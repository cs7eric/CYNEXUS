# 调研发现

## 当前能力

- `PortfolioTradeBO` 已有 id、标的、股票/ETF、BUY/SELL、成交时间、数量、价格、手续费、状态。
- `PortfolioLedgerDomainService` 与 `PortfolioPerformanceDomainService` 已负责持仓、已实现/未实现盈亏、每日/周期绩效和标的贡献。
- `PortfolioOverviewDTO` 已返回成本、市值、现金、总资产、实现/未实现/总盈亏、今日盈亏和交易数。
- UI 入口为 `cynexus-ui/src/views/market/personal-portfolio/index.tsx`，已有持仓、绩效、交易记录、复盘和持仓详情入口。
- 复盘已有 thesis、plan、execution、lessons、nextAction、tags、rating、metricsSnapshot 等字段。
- 交易记录没有交易轮次、策略、止损价、目标价、计划仓位、风险金额、情绪和资金流水字段。

## 指标口径

- 胜率 = 盈利完成轮次 / 完成轮次；平局单独统计。
- 盈亏比 = 平均盈利轮次 / 平均亏损轮次绝对值。
- 盈利因子 = 总盈利 / 总亏损绝对值。
- 期望值 = 胜率 × 平均盈利 - 败率 × 平均亏损绝对值。
- 最大回撤基于账户权益曲线；没有完整现金/入金流水时仅标记为基于组合估值。
- R 倍数只有在计划风险金额或止损价和开仓数量齐全时计算。

## 主要风险

- 多次买入、部分卖出和历史导入基线会影响轮次配对，必须保留配对明细和警告。
- 当前绩效使用价格序列和当前资产估值，不能替代资金加权/时间加权账户收益。
- 策略、计划和标签是用户输入，需版本化保存，不能覆盖原始成交记录。

## 当前实现边界

- 第一阶段当前已实现交易轮次、基础交易统计、日期/标的/类型/结果筛选和 UI 展示。
- `maxDrawdown` 尚未从账户权益曲线计算，UI 明确显示“待账户快照”；策略、标签、持仓周期筛选暂未启用，因为现有成交模型没有这些字段。
- 该分析接口是受 principal/tenant 限制的用户数据读取，暂不暴露给自主 Agent：指标组合和轮次明细可能包含个人交易隐私，且当前接口仍在口径验证阶段；待 API 稳定后再按 bounded read-only tool 评估。
